# Weather-Analytics-DashboarWeather Analytics Dashboard
An interactive dashboard built using live data from a Weather API to display current weather conditions, 7-day forecasts, and air quality insights. The project transforms real-time API data into clear, structured visualizations for quick and practical analysis.
It includes temperature trends, AQI components (PM2.5, PM10, CO, NO₂, SO₂), humidity, wind speed, pressure, and visibility, all presented in a single, user-friendly interface.
Key Features
Real-time weather data via Weather API
7-day forecast trend visualization
Air Quality Index breakdown
Clean, responsive dashboard layout
Purpose
Created to demonstrate API integration, data handling, and effective data visualization using real-world weather data.
